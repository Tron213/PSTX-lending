# ПАСТУХ — презентационный сайт

Адаптивный сайт на русском языке: описание проекта, принцип работы, интерактивный пример истории веса, польза для специалистов и направления развития.

## Открыть в VS Code

1. Распакуйте ZIP-архив.
2. В VS Code выберите **File → Open Folder** и откройте папку `pastukh-site`.
3. Откройте `index.html` в браузере двойным щелчком по файлу.

Сайт работает без сборки, установки Node.js, запуска сервера и подключения к интернету. Меню, анимации и демонстрационный график выполняются прямо в браузере.

Если Node.js и npm уже установлены, в терминале VS Code на Windows можно выполнить `npm start` или `npm run dev`. Обе команды открывают `index.html` в браузере по умолчанию; сервер не запускается. Установка зависимостей не требуется. Используйте `npm run dev`, а не `npm start dev`.

## Файлы

- `index.html` — содержимое и структура страницы, иллюстрация стенда в SVG.
- `styles.css` — цвета, типографика и адаптация к мобильным экранам.
- `script.js` — мобильное меню и переключение демонстрационного графика.
- `components.js` — данные и поведение окон конструкции весов и RFID-метки.
- `components.css` — оформление интерактивных точек и окон конструкции.
- `assets/mark.svg` — знак проекта и favicon.
- `assets/pastukh-project.txt` — скачиваемое описание проекта.
- `package.json` — необязательные команды открытия сайта через npm на Windows.

## Изменения

Тексты редактируются в `index.html`. Цвета задаются переменными в начале `styles.css`. Условные измерения находятся в объекте `examples` в `script.js`. После изменений обновите страницу в браузере.

## Конструкция весов и RFID-метки

В начале `components.js` расположен объект `componentDetails`. Он содержит два элемента: `rfid` (метка) и `scale` (весы). Изменяйте `title` (название), `summary` (описание), `layers` (элементы условной схемы) и `sections` (разделы с заголовком `title` и текстом `text`). Можно добавлять или удалять элементы массивов. Функции ниже объекта менять не требуется.

Материалы и состав пока приведены как заполнитель. Когда появятся подтверждённые характеристики, замените примеры и отредактируйте обозначение заполнителя и примечания в `index.html`. Окна открываются кнопками «+» на иллюстрации либо нажатием на весы и метку. Закрытие: крестик, Escape или нажатие на затемнённый фон. Код `components.js`, `components.css`, `script.js` и `index.html` соблюдает лимит 50 символов в строке.

Сайт презентационный. Данные графика вымышлены и помечены как демонстрация. Подключения к датчикам, серверной базе данных или действующему ИИ нет. Контакты и форма отправки не добавлены, поскольку автор проекта их не предоставил.

## Публикация

Для статического хостинга загрузите `index.html`, `styles.css`, `script.js` и папку `assets`, сохранив структуру. В экспорт не включены служебные данные хостинга Sites и учётные данные.
