# ПАСТУХ — проект для VS Code

Самостоятельная версия сайта: Node.js,
HTML, CSS и JavaScript. Облачные сервисы и
ChatGPT не нужны.

## Запуск

1. Установите Node.js 22.13 или новее.
2. Распакуйте архив.
3. Откройте папку Pastukh-VSCode в VS
   Code.
4. Откройте меню «Терминал → Новый
   терминал».
5. Выполните:

```sh
npm run setup
npm start
```

Команда setup создаёт администратора.
Логин и случайный пароль появятся в
терминале. Сохраните пароль. Пароль
опубликованного сайта в этой копии не
используется. Повторный setup не меняет
существующий пароль. Устанавливать
npm-пакеты не требуется.

Откройте http://localhost:3000 в браузере.
Админ-панель: http://localhost:3000/admin

Для остановки сервера нажмите Ctrl+C. Для
разработки можно использовать:

```sh
npm run dev
```

Сервер перезапускается при изменении кода.
После правок HTML/CSS обновите браузер.
Файлы HTML нельзя запускать двойным
щелчком: для новостей и входа нужен
работающий сервер.

## Новости

В панели нажмите «Добавить новость».
Введите заголовок, текст и выберите файлы.
Нажмите «Опубликовать».

Под публикацией есть «Редактировать» и
«Удалить». При редактировании можно
изменять текст, добавлять и убирать файлы.

До 6 вложений в одной новости. Фотографии:
JPG, PNG, WEBP, GIF, до 10 МБ. Видео: MP4,
WEBM, MOV, до 50 МБ. Для совместимости
рекомендуется MP4.

«Настройки входа» меняют логин и пароль.
Нужно указать текущий пароль. Новый пароль
— не менее 10 символов. После изменения
другие сеансы завершатся.

## Структура

- public/ — страницы, стили и скрипты
  сайта.
- views/ — страницы входа и админ-панели.
- server/index.js — HTTP-сервер.
- server/router.js — маршруты и файлы.
- server/auth.js — пароли и сеансы.
- server/storage.js — локальное хранилище.
- server/routes/ — обработчики API.
- scripts/setup.js — создание
  администратора.
- scripts/check.js — проверка исходников.
- data/ — данные, создаётся при запуске.

Главная страница: public/index.html.
Новости: public/news.html и
public/news.js. Общие стили:
public/styles.css. Стили новостей:
public/news.css. Панель: views/admin.html
и public/admin.js. Карточки конструкции:
public/components.js.

## Формат кода

В текстовых файлах не более 50 символов в
строке, включая пробелы отступов. Длинные
строки JavaScript разбиты через +.
Исходники разделены по назначению. Папка
data содержит рабочие записи JSON;
ограничение ширины к ним не применяется.

```sh
npm run check
```

VS Code показывает вертикальную границу на
50 символах. Не заменяйте форматирование
автоматическим форматтером без проверки.

## Сохранение и резервная копия

Новости, вложения, пароли и сеансы лежат в
папке data. Не удаляйте её. Остановите
сервер и скопируйте всю папку для
резервной копии. Для восстановления
замените data сохранённой копией.

Этот архив содержит исходники сайта.
Публикации и файлы из облачного хранилища
не переносятся: локальная лента начинает
работу пустой. Опубликованный сайт
остаётся отдельным от этой копии.

## Размещение на сервере

По умолчанию сайт доступен только на вашем
компьютере. Для внешнего размещения нужен
Node.js-сервер, постоянный диск и HTTPS.
Разместите сервер за обратным прокси.
Настройте переменные окружения процесса:

- HOST — адрес прослушивания.
- PORT — порт, по умолчанию 3000.
- PUBLIC_URL — полный адрес сайта без /.
- DATA_DIR — путь к постоянному хранилищу.

При HTTPS в PUBLIC_URL cookie получает
флаг Secure. Настройте прокси на тот же
адрес сайта, чтобы проверка Origin
работала. Файл .env автоматически не
читается. Запускайте только один процесс
приложения для одного каталога data.
Ограничитель входа за прокси использует IP
прокси, не доверяя заголовкам от клиента.

## Если забыли локальный пароль

Остановите сервер. Сохраните копию data.
Удалите только файл data/auth/credentials
и выполните npm run setup ещё раз. Новости
и медиа сохранятся, прежние сеансы
перестанут работать. Операция требует
доступа к файлам сервера.
